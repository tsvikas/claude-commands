# claude-commands

A cheatsheet of Claude Code's built-in slash commands and keyboard shortcuts, grouped by task.

- [The page](https://tsvikas.github.io/claude-commands/): the sections side by side. Press a row to read the rest of its line.
- [The cheatsheet](claude-commands.md): the same content as one Markdown file. Its line 4 names the Claude Code version it reflects.
- [The outline](claude-commands-outline.md): every command and key by section and group, names only.

The cheatsheet is the source. The page and the outline are generated from it.
